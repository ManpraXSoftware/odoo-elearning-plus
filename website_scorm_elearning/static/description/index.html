Elearning with Scorm Package

Add SCORM package to make your course more interactable to learners.

Instruction to use this module.

  • No filesystem setup required — uploaded SCORM packages are extracted and stored directly as Odoo attachments, linked to the eLearning content record.
  • Just upload a SCORM ZIP package on a course content item and the module handles extraction, launch-file detection, and version checking automatically.

Key Highlights

  • Added new type (Scorm) for SCORM attachments.
  • Added support to upload Scorm Packages to the Elearning courses.
  • Automatic SCORM version detection from the package manifest, with validation to catch a mismatched manual selection before saving.
